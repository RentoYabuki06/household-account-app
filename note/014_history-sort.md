# 014 履歴の並び替え

## 目的
履歴を日付・金額の昇順/降順で並び替えられるようにする。既定は従来どおり日付の新しい順。

## 変更内容
- `components/ExpenseApp.tsx`: 履歴見出しの右に並び順のセレクトを追加。`sortedExpenses` を useMemo で作り、一覧に使う。

## 設計判断
- 取得済みの月のデータを画面側で並べ替える。再取得が要らず、月の合計や分析には影響しない。
- 金額が同額のときは日付の新しい順にする。

## 動作確認
- `npm run build` が通ることを確認した。
- 未確認: アプリ上での実際の操作。

## 注意点・残課題
- 並び順は月を切り替えても保持するが、リロードで既定に戻る。
