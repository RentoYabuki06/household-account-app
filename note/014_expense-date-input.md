# 014 手入力フォームに日付欄を追加

## 目的
これまで手入力の支出は、常に「今」の日時で登録されていた。過去の日付の支出も入力できるようにする（レシートの読み取り機能の前提でもある）。

## 変更内容
- `components/ExpenseApp.tsx`: 日付の入力欄（`type="date"`、未来の日付は選べない）を追加。`used_at` を入力された日付から作る。登録後は、その日付の月に表示を切り替える

## 設計判断
- **時刻の扱い:** 日付が今日なら現在時刻、過去の日付なら 12:00（日本時間）で登録する。時刻を入力させる欄は設けなかった（手入力で時刻は不要なため）。
- 登録後は、日付を今日に戻す。
- 登録後に切り替える月は、これまでの「今月」から「入力した日付の月」に変えた。過去の月に登録したときに、画面から消えたように見えるのを避けるため。

## 動作確認
- `next build` が通ることを確認した。
- 未確認: 実機での日付の選択、過去の月への登録と表示、月末・月初の日時の境界。

## 注意点・残課題
- 12:00 の固定時刻は、日付の境界（日本時間 0 時付近）でずれないための値。履歴には 12:00 と表示される。
