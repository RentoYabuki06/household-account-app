# 015 月次分析: 前月比較をカレンダー（日別支出）に置き換え

## 目的
月次分析の先頭にあった「前月との比較」は不要なので、同じ位置に日別の支出がわかるカレンダーを置く。

## 変更内容
- `components/AnalysisTab.tsx`: 前月比較の枠を削除し、月カレンダーを追加。各日に支出合計を表示（1万以上は「1.2万」表記、返金などのマイナスは緑）。支出が多い日ほど背景を濃くする。カテゴリ別の「前月 ¥…」表示も削除。支出がない月でもカレンダーは出す。
- `components/ExpenseApp.tsx`: 前月分の取得（prevExpenses）をやめ、`month` を AnalysisTab に渡す。

## 設計判断
- 前月の取得は他で使っていないので、通信ごと削除した。
- 日付の集計は端末のローカル時刻で行う（履歴の表示と同じ基準）。

## 動作確認
- `npm run build` が通ることを確認した。
- 未確認: アプリ上での実際の表示、スマホ幅での金額の収まり。

## 注意点・残課題
- 日付のマスは小さいため、大きい金額は万単位に丸めて表示する。
